# Pantry Sync for Home Assistant

Pantry Sync connects one Pantry household to one Home Assistant to-do list. Shopping items and completion sync in both directions. Pantry inventory is managed separately.

The first package targets Home Assistant OS on amd64. Add this repository’s Git URL under **Settings → Apps → Install app → Repositories**, then select **Pantry Sync**. Follow the [setup guide](pantry_sync/DOCS.md) to preview the first merge before enabling writes.
